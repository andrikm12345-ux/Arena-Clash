## Противоречия: решения нужны до правки

1. **Шкала уровней.** Сейчас 1–9 и всё с уровня 1. Спецификация требует 1–16, старт по редкости, базу «уровня 11» и башни 3052 HP.
2. **Эволюция.** Сейчас первый розыгрыш сразу эволюционный. По спецификации эволюция наступает после N розыгрышей.
3. **Глубина кармана.** Сейчас ~10,5 тайла, в спецификации ~4.
4. **Прыжок тарана через реку.** Делал по прошлой просьбе, а спецификация запрещает наземным реку вне мостов.
5. **Скорости юнитов.** По шкале спецификации бой станет заметно медленнее.
