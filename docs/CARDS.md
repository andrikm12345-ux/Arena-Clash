# Схема карты

Карты лежат в таблице `CARDS` в `src/1-data.js`. Числа даны для уровня 11. Каждый уровень меняет здоровье и урон на ±10% (`LV`). Стартовый уровень зависит от редкости (`START_LV`): обычная 1, редкая 3, эпическая 6, легендарная 9, чемпион 11.

Единицы: расстояния в тайлах, время в секундах. Скорость задаётся классом (`CFG.speed`): slow 45, med 60, fast 90, vfast 120; 60 = 1 тайл/с.

| Поле | Смысл |
|---|---|
| `n` | Имя |
| `rar` | Редкость: `common`, `rare`, `epic`, `legendary`, `champion` |
| `type` | Тип: `troop` (войско), `building` (здание), `spell` (заклинание). Чемпион — войско с `ability` |
| `cost` | Стоимость в эликсире |
| `count`, `unit` | Сколько юнитов выходит и какой карты (по умолчанию — сама карта) |
| `hp`, `dmg`, `hit` | Здоровье, урон, пауза между ударами |
| `fh` | Первый удар после захвата цели. По умолчанию `hit × CFG.unit.fh` |
| `wind` | Замах. По умолчанию `min(hit × CFG.unit.wind, CFG.unit.windMax)`. Если цель умерла до конца замаха, удар отменяется |
| `rng` | Дальность. Ближний бой — 0,5–1,2; дальний — от 2 |
| `sight` | Обзор. По умолчанию: «только здания» 7,5; дальнобойные — дальность + 0,5; остальные 5,5 |
| `spd` | Класс скорости |
| `tg` | Цели: `g` — земля, `ga` — земля и воздух, `b` — только здания |
| `fly` | Летает |
| `dep` | Время развёртывания (по умолчанию 1) |
| `splash`, `spin`, `proj` | Сплэш: радиус. `spin` — круговой вокруг себя. С `proj` — в точке попадания снаряда |
| `r`, `mass` | Радиус коллизии в точках арены (тайл = 20) и масса для расталкивания: тяжёлый толкает лёгкого |
| `knock` | Отбрасывание: скорость с затуханием (`CFG.phys`). Сбрасывает замах и цель. Тяжёлых и летающих не толкает |
| `stun`, `slow`, `freeze` | Оглушение, замедление `{f, t}` и заморозка. Оглушение и заморозка сбрасывают рывок, замах и разогрев луча |
| `charge` | Рывок: после разгона двойная скорость и удар ×2 |
| `beam` | Луч с разогревом: `{dmg:[...], t:[...]}` — урон ступеней и сколько держать до следующей |
| `chain` | Сколько целей бьёт молния |
| `death` | Урон при смерти: `{dmg, r}` |
| `dspawn` | Кто появляется при смерти: `{id, n}` |
| `spawn` | Спавнер: `{id, every, n}` |
| `life` | Время жизни здания; здоровье убывает линейно |
| `rad`, `tdmg` | Заклинание: радиус и урон по башням (обычно 20–35% полного) |
| `waves`, `poison`, `rage` | Волны, длительность яда, ярость |
| `tunnel`, `td`, `jump` | Роет ход; множитель урона по зданиям; прыгает через реку |
| `kami` | Взрывается при атаке |
| `noStart` | Не попадает в стартовую руку |
| `pull`, `pullSpd` | Вихрь: сколько секунд тянет и скорость затягивания. Юнитов тяжелее `CFG.phys.pullMass` тянет слабее |
| `heal`, `healT` | Лечение своих в радиусе: сколько здоровья и за сколько секунд |
| `elx` | Здание добывает эликсир: `{every, n}` |
| `aff` | Сродство: `'day'` или `'night'` — в своё время суток +25% урона и +15% скорости (`CFG.cycle.aff`) |
| `light` | Свет вокруг юнита или здания, клеток. Ночью враг виден только в свете или ближе 2,5 клетки |
| `flash`, `blind` | Вспышка: `{light, t}` — временный свет; `blind` — оглушение в радиусе |
| `force` | Принудительное время суток: `{k: 1 ночь / 0 день, t}` секунд, вход и выход по 2 с |
| `stealth` | Ночью виден только вблизи 2,5 клеток, свет не открывает |
| `shade` | Сумрак: сколько секунд в круге не действует свет |
| `bdmg` | Урон мосту. Мост рушится на 20 с при 2000 урона (`CFG.bridge`) |
| `roll` | Каток: `{len, spd}` — сколько клеток катится и как быстро. Ширина = `rad × 2`. Каждого бьёт один раз и толкает по ходу |
| `shield` | Щит: принимает урон первым; пока он цел, юнита не толкают и не оглушают |
| `minRng`, `siege` | Мёртвая зона здания (клетки); `siege` — здание стреляет и по зданиям с башнями |
| `grave` | Заклинание-кладбище: `{t, n, id, td}` — за `t` секунд поднимает `n` юнитов `id` в круге; `td` — множитель их урона по зданиям |
| `dash` | Рывок к цели: `{min, max, spd, mul}`: дистанция в тайлах, скорость, множитель удара. Во время рывка неуязвим |
| `ability` | Способность чемпиона или героя: `{k, n, cost, cd, ...}` |

Эволюции (`EVO`) и герои (`HERO`) описаны рядом в том же файле. Башни, режимы, правила и уровни ботов — в `src/0-config.js`.
